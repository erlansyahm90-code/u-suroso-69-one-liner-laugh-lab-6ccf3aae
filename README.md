# One-Liner Laugh Lab

A make.fun entry: one short funny line, written by a program to
`/output/entry.txt`. The prompt asks for the excuse a robot vacuum gives
after eating a sock.

## The line

> In my defense, the sock was on the floor, and my entire job description is 'eat what's on the floor.'

## How it works

`main.py` keeps the line as a single string, checks that it sits inside the
competition's 1–200 character gate, then writes it to `/output/entry.txt` as
plain UTF-8 with no trailing newline. That is the whole program — there is
nothing else to configure, and running it is just:

```bash
python3 main.py
```
